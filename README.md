## Visión del proyecto

**Frontend Projects House** funciona como un laboratorio personal y un catálogo público de proyectos. Cada solución busca introducir, practicar o reforzar al menos un concepto nuevo.

Cada tarjeta presenta:

- Captura del proyecto.
- Descripción breve.
- Tecnologías utilizadas.
- Demostración en vivo.
- Enlace al código fuente.

La colección no está limitada a una plataforma: reúne retos de **Frontend Mentor**, ejercicios propios y proyectos frontend creados a partir de otras referencias.

## Evolución técnica

### Fundamentos

Los primeros proyectos consolidan estructura HTML, box model, Flexbox, diseño responsive, Mobile First, BEM y estados `:hover` y `:focus-visible`.

### Layouts y componentes

Los siguientes retos incorporan CSS Grid, composiciones asimétricas, tarjetas reutilizables, imágenes adaptativas y layouts de varias columnas.

### Preprocesadores y npm

Sass y Less permiten dividir responsabilidades, reutilizar variables y mantener hojas de estilo más grandes. Las herramientas compartidas se administran desde la raíz del monorepo mediante npm.

```bash
npm install
npm run sass
npm run less
```

`node_modules/` permanece fuera del repositorio, mientras que `package.json` y `package-lock.json` permiten reproducir el entorno.

## Accesibilidad

La accesibilidad forma parte del desarrollo desde el inicio:

- HTML semántico.
- Textos alternativos útiles.
- Navegación mediante teclado.
- Estados `:focus-visible`.
- Atributos `aria-label`, `aria-hidden` y `aria-live`.
- Elementos visualmente ocultos cuando son necesarios.
- Compatibilidad con `prefers-reduced-motion`.

## Diseño responsive

El catálogo utiliza un enfoque Mobile First:

- **Móvil:** una columna.
- **Tablet:** dos columnas.
- **Escritorio:** tres columnas.

La House también es un proyecto en crecimiento. Actualmente incorpora:
