## What I Learned

</div>

In this project, I learned how to:

- Use semantic HTML for editorial content.
- Divide long content using `<section>`.
- Use `<aside>` for supplementary information.
- Create ordered and unordered lists.
- Customize list markers with `::marker`.
- Use `<strong>` to highlight important information.
- Create a semantic table using `<table>`, `<tr>`, `<th>`, and `<td>`.
- Use `scope="row"` to improve table accessibility.
- Create dividers using `border-bottom`.
- Design a mobile version first, without an outer card.
- Transform the page into a centered card for desktop.
- Extract reusable components for content, lists, and tables.
