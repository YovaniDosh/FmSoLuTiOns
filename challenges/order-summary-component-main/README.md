## Overview

</div>

The goal was to build an order summary card with:

- Main illustration.
- Service description.
- Plan summary.
- Link to change the plan.
- Payment button.
- Cancel button.
- Responsive decorative background.

## What I Learned

</div>

- Organizing classes using the BEM methodology.
- Separating a component into a block and its elements.
- Creating a solid offset shadow.
- Applying interactive states with `:hover`.
- Using a local variable font.
- Building a mobile-first component.
- Creating a responsive background using different images for mobile and desktop.
- Applying decorative images with `background-image`.
- Applying soft shadows to cards and buttons.
- Creating `hover`, `focus-visible`, and `active` states.

```css
@media (prefers-reduced-motion: reduce) {
  *,
  *::before,
  *::after {
    transition-duration: 0.01ms;
  }
}
```
