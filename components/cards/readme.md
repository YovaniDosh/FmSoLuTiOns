# Cards

Base reutilizable para componentes visuales contenidos.

## Clases

- `.card`
- `.card__content`

## Personalización

El componente usa variables CSS:

```css
:root 
{
  --card-radius: 1.25rem;
  --card-background: white;
  --card-shadow: 0 1.5rem 2.5rem hsl(245 75% 52% / 0.16);
  --card-padding: 2rem;
}
