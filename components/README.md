# Biblioteca de componentes

Colección de patrones reutilizables extraídos de los desafíos de Frontend Mentor.

Los proyectos individuales permanecen independientes. Esta biblioteca documenta y conserva versiones genéricas de los patrones aprendidos.

## Categorías

- `buttons/`: botones y variantes.
- `cards/`: estructuras base para tarjetas.
- `badges/`: etiquetas y estados.
- `links/`: enlaces interactivos.
- `forms/`: campos, labels y validaciones.
- `layouts/`: estructuras de página.
- `navigation/`: menús y navegación.
- `modals/`: ventanas y overlays.
- `utilities/`: clases auxiliares.
