# Buttons

Componente reutilizable para acciones principales y secundarias.

## Variantes

- `.button`
- `.button--full`
- `.button--primary`
- `.button--secondary`

## Estados incluidos

- Hover
- Focus visible
- Active
- Reduced motion

## Origen

La primera versión surgió en Product Preview Card y fue ampliada en Order Summary Component.

## Uso

```html
<button class="button button--primary button--full">
  Proceed to Payment
</button>

<button class="button button--secondary button--full">
  Cancel Order
</button>
