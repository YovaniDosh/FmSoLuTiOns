# Frontend Mentor House — Brandbook

## Identidad

Frontend Mentor House es una colección visual y documentada de desafíos frontend.

## Principios

- Mobile-first.
- Código legible.
- Accesibilidad.
- Reutilización.
- Documentación progresiva.
- Diseño consistente.

## Tipografía

### Display

Believe

Uso:

- Título principal de la House.
- Elementos destacados.

### Interfaz

Inter, system-ui, sans-serif

Uso:

- Subtítulos.
- Tarjetas.
- Botones.
- Navegación.
- Texto general.
